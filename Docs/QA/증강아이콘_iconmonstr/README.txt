증강 아이콘 (iconmonstr) 받는 곳

1. https://iconmonstr.com 에서 아이콘을 골라 "Lined"(선) 버전의 SVG를 받는다.
   - Filled(채운) 버전은 쓰지 않는다 (선만 사용 원칙).
2. 이 폴더에 넣는다. 파일 이름은 아래 표의 "번호_이름" 으로 해 주면 가장 좋다.
   예) 001_맥동탄.svg  /  084_블랙홀 포획.svg
   번호만(001.svg) 또는 이름만(맥동탄.svg) 이어도 알아볼 수 있다.
3. 못 찾은 증강은 비워 두면 된다. 그 증강은 지금 시트의 추천 아이콘을 그대로 쓴다.

  - 상업적 사용 가능, 출처 표기 불필요, 수정 가능
  - 아이콘 자체 판매/재배포, 로고·상표 사용 금지
  - 사이트 전체를 한꺼번에 받는 것은 금지 → 필요한 것만 하나씩 받기
