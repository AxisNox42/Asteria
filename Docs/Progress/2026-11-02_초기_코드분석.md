## 3. 버그 / 위험 (우선순위 순)

### 즉시 수정 권장
1. ✅ **macOS 빌드 실패**: `main.cpp:3812` `sscanf_s`, `:3817` `fopen_s`에 `_MSC_VER` 가드가 없음. CI가 **0.3.1~0.3.5 다섯 번 연속 실패** 중.
2. ✅ **관통 탄이 같은 적을 여러 번 맞힘**: `Bullet`에 이미 맞힌 대상 기록이 없음. 관통에 성공하면 탄이 살아남아 다음 스텝에 같은 몹을 다시 맞힘(`CollisionSystem.h:239`). 큰 적일수록 피해가 3~4배로 늘어남. 도탄(`RicochetTo`)도 같은 문제.
3. ✅ **설정 화면에서 ESC를 누르면 무조건 저장됨**: `SceneMenus.cpp:1420` `TryEscNavigateBack`이 `SaveGame()`을 호출 → "변경사항 확인" 대화상자와 "SAVE 버튼으로만 저장" 정책이 무시됨.
4. **빌드 스크립트가 이 PC에서 동작하지 않음**: `scripts/build_windows.ps1`이 `C:\Program Files\...\2022`에서만 MSBuild를 찾음. 이 PC의 VS는 `D:\VisualStudioCommunity`에 있음. vswhere를 쓰도록 바꿔야 함. ps1이 BOM 없는 UTF-8이라 PowerShell 5.1에서 한글 출력이 깨짐.

### 확인 필요
5. 일시정지 인벤토리에서 ESC를 누르면 게임이 바로 재개될 가능성 (`GameManager.cpp:148` → `main.cpp:4570`).
6. 키 바인딩으로 SPACE, 1/2/3을 지정할 수 있는데, 이 키들은 일시정지·증강 선택에 하드코딩되어 충돌함 (`KeyBindings.h:61-65`).
7. 해제된 포인터와 비교하는 ABA 문제: `EnemySpawner.cpp:24,107` `eliteMob`, `Bullet::wardPassed`.
8. CAELUM 전역 상태: 사망 연출 중에 두 번째 CAELUM이 생기면 첫 번째 상태가 초기화됨 (`Monster.h:757`).
9. Antares 분열체 HP가 런 배율을 무시함 (`MonsterManager.h:202`). 의도한 것인지 확인 필요.
10. 세이브: fsync 없음, rename 두 번 사이에 크래시가 나면 구 세이브 이전 로직이 .bak보다 우선할 수 있음, macOS에는 중복 실행 방지가 없음. Reset 시 `g_RunStardust`가 초기화되지 않음.
11. macOS에서 `os_pane`이 빈 구현이라 NORMA 창 패턴이 동작하지 않음. 보스전 QA 필요.
12. `StartBgm`이 path와 상관없이 항상 같은 곡을 로드함 (`Audio.cpp:133`).
13. 성능: 유도탄마다 최근접 적을 탐색(탄 수 × 몹 수), 몹끼리 밀어내기가 O(n²), 그라디언트를 그릴 때마다 배치 flush, 글리프 캐시에 상한이 없음.
14. GL 자원 해제는 TextRenderer에만 있음. 셰이더 컴파일이 실패해도 계속 진행함.

## 4. 현지화 (KR/EN/JP) 점검

- 글리프 누락은 0건 (폰트 체인 실측). 다만 일본어 문장의 `、。「」〜`는 한글 폰트(Orbit)로 그려져 서체가 섞임.
- ✅ 깨진 문자열: `main.cpp:6398` JP `"F: ?化"` (CREATIVE HUD). `AugmentCatalog.cpp`의 RESERVED_AUG(삭제된 증강) KR/JP 문자열이 `"??"`로 손실됨. 표시되지 않는 항목이라면 영향은 작음.
- 하드코딩 영어: CREATIVE 설정 화면(`SceneRunConfig.cpp:176,189`), `"STAT DELTA"`(`SceneAugment.cpp:1321`), 튜토리얼 제목 `"ASTRAL FIELD GUIDE"`. KR 번역표에 `"Score"`가 영어로 남아 있음.
- 용어 불일치:
  - 도감: EN `ASTRAL LOG` ↔ `Codex`, JP `星界記録` ↔ `図鑑`
  - 디버프 ↔ 너프 (튜토리얼·READY 화면)
  - JP 증강: `強化`가 상점 업그레이드와 같은 단어. `増強`이 한 곳에 섞여 있음
  - JP 메인 메뉴만 `スタート`, 나머지는 `プレイ`
- 어색한 JP: `窓動作`, `組合強化`, `ガラスの大砲` / 구분자 `·`와 `・`가 섞여 있음.
- 증강 상세 설명이 KR에만 있음 (`AugmentDescKR.h`). EN/JP 사용자는 정보가 적음. ID `DMG+5`인데 실제 수치는 +9.
- 구조: 번역 방식 5가지(StrId, LStr, `[3]` 배열, ShopText, 삼항 연산자), 언어 인덱스 함수 3가지가 섞여 있음. 미사용 StrId 13개, 미사용 `LanguageFace()`/`LanguageFontChain()`.
