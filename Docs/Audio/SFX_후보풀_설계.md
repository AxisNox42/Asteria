# SFX 설계 — 묵직한 SF 임팩트 (후보 풀에서 응집 선택)

이전 세트는 모두 교체했다. BGM(`bgm_main.mp3`)은 건드리지 않았다.

**방향은 '묵직한 SF 임팩트'**다(사용자 선택). 이전 피드백도 그대로 반영했다.
- 무게 있게
- 타격은 모래주머니처럼 짧고 묵직하게
- 전체 느낌을 맞추기
- CC0만, 후보는 효과음당 20개 이상

## 1. 방법 (`scripts/sfx_pool/`, 재현 방법은 `README.md`)

### 1) 모으기 (`collect.py`)
- 효과음마다 SF 계열 검색어 6~11개로, 쪽마다 상위 8개씩 2쪽을 봤다.
- **지금까지 쓴 소리 35개는 제외**했다.
- 효과음당 후보 20~44개, 모두 **461개**가 모였다. 미리듣기를 모두 받아 분석했다.

### 2) 역할 적합 (`pick_set.py`, 통과해야 후보)
| 항목 | 기준 |
|---|---|
| 길이 | 타격은 선택 때 300 ms까지 허용하고, 처리에서 짧게 자른다 |
| 음높이 방향 | 확정·스킬·레벨 업은 상승, 뒤로·사격·사망은 하강 |
| 모래주머니 | 타격 3종은 100~400 Hz 몸통이 30 % 이상 |
| UI 날카로움 | ≤ 1.75 acum |
| 8 kHz 위 | 과한 것은 제외 |
| 방향 필터 | 레트로·8비트·PS1·장난감·sfxr 계열과 목소리는 제외. 타격 자리에서는 휘두르는 바람 소리도 제외 |

### 3) 점수
- **적합**
  - 다운로드 수(커뮤니티 검증)
  - **무게**: 100~400 Hz 몸통 × 0.8 + 200 Hz 아래 × 0.4. UI는 몸통 × 0.3
  - 윤곽의 분명함
  - SF 계열 제목 +0.5, 역할 이름과 맞는 제목 +0.6
  - 다른 UI 역할 이름이면 −0.8. 예: 호버 자리에 'Cancel'
- **응집**: 이미 고른 소리들의 평균과의 질감 거리(잡음성·스펙트럼 기울기·변화량·어택·밝기)만큼 뺀다.
- **제약**: 전투음 구별(음색 거리 ≥ 0.8), 크기 ↔ 밝기(피격 > 처치 > 폭발)
- 처음 고른 소리(처치)는 묵직한 베이스 임팩트다. 나머지는 그 소리를 기준으로 차례로 골랐다.

### 4) 결과 응집도
고른 세트의 평균 질감 거리는 **2.08**이다.

비교를 위해, 역할에 맞는 후보 중에서 무작위로 짠 세트 2,000개를 만들었다. 그 중앙값은 2.67이고 하위 5 %도 2.39였다. 고른 세트는 **무작위 세트 2,000개 전부보다 촘촘하다**.

## 3. 처리 (`scripts/build_sfx.py`)

**공통(무게, `WEIGHT`).** 작은 스피커는 100 Hz 아래가 거의 들리지 않는다. 그래서 다음을 걸었다.

| 처리 | UI | 반복 전투음 | 타격 | 큰 사건 | 근거 |
|---|---|---|---|---|---|
| 피치 내림 | −2반음 | −3 | −2 | −3 | 낮은 음 = 크고 무거움 (Parise & Spence 2009) |
| 180 Hz 몸통 EQ | +3 dB | +5 | +5 | +4 | 작은 스피커에서 들리는 '두께' |
| tanh 포화 | 없음 | 1.6 | 2.0 | 1.6 | 저음 배음 |
| 라우드니스 | +2 LU | +2 | +1 | +2 | 큰 소리 = 큰 것 (Grassi 2005) |

그 밖의 공통 처리: 모노, 앞 무음 제거, 실제 피크 ≤ −1 dBTP, 8 kHz 위 정리, 짧은 잔향.

**소리별(`EXTRA`):**
- 타격 3종: 120~180 ms로 자르고 지수 감쇠(τ 35~60 ms)를 건다. SF 임팩트의 긴 꼬리를 모래주머니처럼 짧게 만든다.
- 몸통 킥(100~220 Hz 사인): 사격, 전격, 대시, 스킬, 레벨 업, 별가루.
- 폭발: 몸통 EQ +8 dB, +3반음.
- 사망: 저역통과, −3반음, 포화 뒤 한 번 더 저역통과.

| 항목 | 결과 |

| 즉시성, 길이, 계층, 피크, 8 kHz 위, 날카로움 | 16개 통과 |
| 무게(100~400 Hz 몸통) | UI 0.10, 반복 0.20, 타격·사건 0.30 이상 통과 |

이번에 바꾼 검사 기준:
- **크기 순서에서 사망을 뺐다.** '전원 꺼짐'은 물체 크기가 아니고, 고를 때도 같은 기준이었다.
- **큰 사건의 음높이 방향은 60 Hz부터 본다.** 피치를 내려 움직임이 저역으로 갔다.

## 5. 한계

- 듣고 확인하지 않았다. 'SF 느낌'은 검색어와 제목으로만 걸렀다.
- 대시는 '나무 막대 휘두르기' 녹음이다. SF 계열 대시 후보 중 무게·응집 점수에서 앞서는 것이 없었다.
- 적합 후보가 적은 효과음이 있다. 처치 3개, 스킬 시전 3개, 확정 4개다. 마음에 들지 않으면 그 효과음만 검색어를 늘려 다시 고르면 된다(`scripts/sfx_pool/README.md`).

## 6. "뭔가 아쉽다" 분석과 수정 (2026-11-03)

### 원인 (측정)

1. **'딱'(1~5 kHz)이 없었다.** 어택 20 ms의 1~5 kHz 비율 중앙값이 1 %였다. 단단함은 어택의 밝기에서 온다(Freed 1990).
2. **무게를 과하게 좇았다.**
   - 80~250 Hz 비율 중앙값이 66 %였다.
   - 선택 점수가 저역 '비율'을 보상해서, 60 Hz 아래 럼블이 큰 녹음이 뽑혔다. 처치 56 %, 대시 41 %였다.
   - 처리(피치 −3, 몸통 +5 dB, 8 kHz 저역통과)가 더 어둡게 만들었다. 95 % 에너지 대역이 656에서 480 Hz로 내려갔다.
3. **응집이 획일이 됐다.** 전투음 밝기 퍼짐이 0.62 옥타브로 가장 좁았다. 모든 소리가 같은 음역이라 두드러지는 소리가 없었다.
4. **느린 어택.** 호버·확정·스킬·대시가 40~90 ms였다.
5. **엔진에 남은 이전 설정.**
   - 사격·피격·처치의 피치 랜덤이 0이라 기관총처럼 똑같았다.
   - 파생 큐(웨이브 시작 −12, 보스 처치 −5/−7/−12 등)가 이미 어두운 소리를 더 내렸다.
6. BGM 가림은 원인이 아니었다. 모든 효과음이 BGM보다 18~31 dB 컸다.

### 수정

| 단계 | 바꾼 것 |
|---|---|
| 선택 (`features.py`, `pick_set.py`) | 60 Hz 아래 비율·80~250 Hz 비율·어택 1~5 kHz('snap')를 새로 측정한다. 60 Hz 아래가 25 %를 넘는 녹음은 제외한다. 부드러운 소리를 뺀 역할은 **원본에 '딱'(어택 1~5 kHz ≥ 10 %)이 있어야** 후보가 된다. 무게 점수는 80~250 Hz × 0.6 + snap × 0.8. 응집 벡터의 밝기 가중은 0.5에서 0.15로 낮췄다(역할마다 밝기가 달라도 되게). |
| 처리 (`build_sfx.py`) | 60 Hz 고역통과로 럼블을 없앴다. 무게 처리는 약하게 했다(피치 0~−2, 몸통 0~+3 dB, UI는 없음). 8 kHz 저역통과를 16 kHz로 올렸다. 앞부분은 2 %에서만 자른다(세게 자르면 원본의 크랙이 잘린다). 앞 15 ms의 1 kHz 위만 키운다. '딱' 층(1.5~5 kHz)은 목표 비율에 맞춰 소리마다 크기를 계산한다. 몸통 킥은 8 ms 늦게 시작한다('딱' → 몸통 순서). |
| 엔진 (`Audio.cpp`) | 사격·피격·처치에 ±1반음 랜덤. 파생 큐의 큰 피치 내림을 −2~−5로 줄였다. |
| 검사 (`check_sfx_fit.py`) | '선명함'(어택 1~5 kHz ≥ 8 %, 기준값은 근거 없는 선택으로 이전 중앙값의 약 8배), '럼블'(60 Hz 아래 ≤ 10 %), '쨍함'(8 kHz 위 ≤ 8 %)을 추가했다. UI는 무게 기준을 뺐다. 음높이 방향은 앞 20 ms를 빼고 본다. |

## 10. 호버 = 원래 사격음, 클릭 = 마우스 클릭 원음 (2026-11-03, 요청)

**호버**

## 11. 클릭 = '딸깍' 마우스 클릭 (2026-11-03, 요청)

**원인:** 10절의 클릭(Basic Mouse Click UI)은 유효 7 ms짜리 한 번의 '틱'이었다. 마우스 버튼의 '딸깍'으로 들리지 않았다.

**다시 고르기**
- 단일 마우스 클릭 후보 72개를 모았다. 더블·스크롤·키보드는 뺐다.
- '딸깍' = **누르는 '딸' + 놓는 '깍'**으로 정의했다.
  - 1 ms 엔벨로프에서, 첫 타격의 25 % 이상인 두 번째 타격이 30~200 ms 뒤에 오면 가산한다.
  - 앞 50 ms의 1.5~6 kHz(플라스틱 '딸깍' 대역)를 함께 본다.
  - 여러 번 딸깍인 소리와 350 ms가 넘는 소리는 제외했다.

**선택:** mouse click (Weak_Hero)
- 누름 → 뗌 간격 106 ms, 길이 114 ms, 제목에 mouse
- 같은 점수인 Classic Click(adh.dreaming)은 마우스인지 제목으로 확인되지 않아 대안으로 남겼다.

**처리:** 원음 그대로에 6.5 kHz 저역통과만 걸었다. '딸깍'의 1.5~6 kHz는 두고, 그 위의 쨍함(귀 피로)만 덜어냈다.

**검사:** 확정은 사용자가 고른 밝은 소리라서 UI 날카로움 상한(1.75 acum)에서 뺐다. 측정값은 2.20 acum이고, 8 kHz 위 에너지 기준(쨍함)은 통과했다.

## 13. 타격·피격 = 자연 감쇠 (2026-11-03, 피드백: "전이랑 거의 똑같고 너무 심하게 끊긴다, 다른 시도")

- 엔진: 보이스가 모두 재생 중이면 꼬리(75 % 이후)에 들어간 보이스만 재사용하고, 아니면 새 소리를 버린다 (`AcquireVoice`).
