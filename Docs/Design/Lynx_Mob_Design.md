# LYNX 일반 몹 설계

작성일: 2026-11-05

LYNX는 거리를 벌린 채 코어에서 광선을 쏘는 일반 저격 몹이다. CARINA 엘리트로 시작했다가 작옵과 쌍포를 없애고 일반 몹으로 내렸다. 코드 상수는 `WiNILL/Entity/LynxMob.h` 한 곳에 모여 있고, 아래 수치는 모두 플레이 검증 전 초안이다.

## 외형

사용자 그림판 스케치를 따른다. 곡선 없이 직선만 쓴다.

- 긴 삼각 판 두 장이 마름모 코어를 양옆에서 감싸고, 앞쪽 끝이 좁게 모인다. 두 판은 거울 대칭이다.
- 판 두 장과 마름모가 몸체의 전부이고, 코어 별 하나만 더했다. 안쪽 장식선은 넣지 않는다.
- 앞코에서 뒤끝까지 약 90px이다.

## 공격: 저격

1. 쉬는 시간 2.2초 동안 거리를 조절한다.
2. 조준 1.2초 동안 그 자리에 고정되어, 코어에서 뻗은 가는 조준선으로 플레이어의 현재 위치를 따라간다. 예측 조준은 하지 않는다. 초당 2.4라디안으로 돌고, 선과 몸체가 점점 달아오른다.
3. 고정 0.25초 동안 각도가 잠기고 선이 밝게 깜빡이며, 레이저가 채울 폭 32px가 흐리게 표시된다.
4. 코어에서 선을 따라 폭 32px의 레이저를 쏜다. 탄이 날아가지 않는 즉시 판정이고, 사거리는 무한이며, 플레이어 몸이 레이저에 닿으면 맞는다(중심선에서 기본 26px, 플레이어 크기에 비례). 피해는 12다.

선이 멈춘 뒤 옆으로 비켜나면 피할 수 있다.

조준부터 발사가 끝날 때까지 LYNX는 밀리거나 경직되지 않는다. 플레이어가 본 선 그대로 광선이 나가게 하기 위해서다. 조준선은 몸체와 따로 그려서 레굴루스 은신 중에도 흐려지지 않고, 어두운 테두리로 밝은 배경에서도 보이게 한다.

## 스탯

| 항목 | 값 |
|---|---|
| 체력 | 로터의 2.4배 (기본 216) |
| 이동 | 로터의 0.45배 |
| 유지 거리 | 380~520px |
| 접촉 피해 | 초당 4 |
| 보상 | 경험치 5, 점수 240, 스타더스트 3 |

## 등장

일반 웨이브 명단에 있다. NORMAL은 6웨이브, HARD와 NIGHTMARE는 7웨이브부터, 확률 5%에서 시작해 10%까지 오른다. EASY에는 나오지 않는다. 동시에 3마리까지만 나오고, 넘치는 몫은 로터가 된다.
