# 증강 시너지 설계 — 실수 체력(100) 기준 (v0.3, 2026-11-04)

전체 카드 표는 `Docs/QA/Asteria_증강기획_시너지_v1.xlsx` (110장), 데이터와 계산기는 `WiNILL/Entity/AugmentSynergy.h`, 검증은 `scripts/test_augment_synergy.ps1`이다. 이 문서는 구조와 규칙만 적는다. 기존 카드 수치 조정은 [Augment_Balance_Pass_2026-11-04.md](Augment_Balance_Pass_2026-11-04.md).

## 1. 체력 규칙

체력은 **100 기준의 실수 값**이다. 자연 재생(3초당 1), 최대 체력 성장 카드(체력 증가, 체력 강화), 회복 카드는 지금 그대로다. 시너지 모델은 평균 피격 10, 분당 약 10회 피격을 가정하고, 보호막은 "피격 1회를 막는 횟수"로 센다.

체력이 성장 축으로 남아 있으므로 대가 카드(유리대포, 이단의 서약 등)는 최대 체력을 직접 깎는다 (유리대포는 최대 체력 30으로 고정).

## 2. 시너지를 만드는 원칙 (참고 문헌)

**검색으로 존재를 확인한 자료**
- Cedotal, A. *Life, Liberty, and the Pursuit of Comboness*, Roguelike Celebration 2024 ([슬라이드](https://speakerdeck.com/cedotal/life-liberty-and-the-pursuit-of-comboness-roguelike-celebration-2024-talk)) — 콤보는 "함께일 때 합보다 가치가 크고 가치가 자명하지 않은 업그레이드 부분집합".
- Moraes Júnior, J. M. L. (2021). *Sinergia entre mecânicas de jogos digitais do gênero deckbuilder roguelike* (UFC 학부 논문, [저장소](https://repositorio.ufc.br/ri/handle/riufc/68404)) — Slay the Spire의 시너지를 Schell의 렌즈로 분석.
- Jaffe 외 (2012) *Evaluating Competitive Game Balance with Restricted Play*, AIIDE ([논문](https://ojs.aaai.org/index.php/AIIDE/article/view/12513)) — 단순한 기준 행동으로 이상치를 찾는 밸런스 방법.

**기억에 의존한 고전 문헌 (인용 전에 원문 확인 필요)**: Sicart (2008) *Defining Game Mechanics*, Game Studies; Hunicke·LeBlanc·Zubek (2004) *MDA*; Björk·Holopainen (2005) *Patterns in Game Design*; Adams·Dormans (2012) *Game Mechanics: Advanced Game Design*; Cook (2007) *Game Design Skill Atoms*.

단일 논문이 "탄막 로그라이크 증강 시너지"를 직접 다루지는 않는다. 위 자료에서 가져온 원칙은 다음 넷이다.
1. 규칙을 바꾸는 카드가 숫자를 키우는 카드보다 시너지가 크다. → 단순 수치 증가 카드는 표에서 뺐다 (골랐을 때 변화를 느끼기 힘들다).
2. 모든 카드는 역할 1개와 태그를 가진다.
3. 조합이 만드는 결과는 카드 설명에 쓰지 않는다. 설명에는 자기 규칙만 쓴다.
4. 파괴적 조합은 막지 않고 비용을 붙인다.

## 3. 역할과 태그

| 역할 | 하는 일 | 예 |
|---|---|---|
| 프레임 | 기본 무기의 모양을 바꾼다 (런에 1개) | 미니건, 레이저, 샷건, 저격총, 점사총, 석궁 |
| 동사 | 탄이 하는 행동을 추가한다 | 도탄, 관통탄, 분열탄, 유도탄, 파열탄, 쌍발탄, 점화탄 |
| 트리거 | "~할 때마다" 조건을 만든다 | 박자 추가탄, 처치 반응, 튕김 연쇄 |
| 증폭 | 필요한 태그가 있을 때만 켜지는 조건부 효과 | 도탄 증폭, 방벽 폭발, 점사 증폭 |
| 대가 | 힘을 주고 체력·이동·방어를 가져간다 | 유리대포, 이단의 서약, 고행 |
| 보호 | 피해를 막는 수단 | 보호막 충전, 완충 착지, 최후의 방벽 |

카드는 "붙이는 태그"와 "필요한 태그"를 가진다. 필요한 태그가 없으면 그 카드는 효과가 꺼진다 ("죽은 카드"). 태그 31개의 뜻과 어느 카드가 주고 받는지는 시트의 `태그 사전`, `시너지 지도`에 있다. 모든 태그에 받는 카드가 있다.

같은 동사도 프레임에 따라 다르게 해석된다 (시트 `프레임 변환표`). 예: 도탄은 기본 탄에서는 벽 튕김, 레이저에서는 빔 반사다. 추가로 쏘는 탄은 원래 탄의 태그를 물려받는다.

### 겹치는 카드를 줄이고 새 규칙의 카드를 넣은 기록 (2026-11-04)

- **34장 삭제** — 같은 일을 하는 카드(예: 튕김 반응 ≈ 도탄 증폭, 보호막 변종 넷), 피해 수치만 올리는 증폭(유도 정밀, 체공 증폭, 마지막 한 방 …), 효과가 약한 카드(서리탄, 저주받은 별). 카드별 이유는 시트 `정리한 카드`에 있다.
- **새 카드 31장** — 모두 "골랐을 때 플레이가 달라지는" 규칙이다.

| 갈래 | 카드 | 하는 일 |
|---|---|---|
| 프레임 | 파동포, 박격포 | 모든 적과 적탄을 지우며 나가는 거대 파동 / 조준한 자리에 떨어져 터지는 포탄 |
| 도박 | 주사위탄 + 눈금 조작 | 발사마다 관통·분열·튕김·폭발 중 하나를 무작위로 얻음 |
| 위치 | 자리바꿈탄 + 교환 폭발, 잔영 탄막, 대시 폭죽, 도약 연계 | 맞힌 적과 자리를 바꾸고 (대시로 취급), 대시한 길에 탄막을 남기고, 대시가 끝나면 사방으로 쏨 |
| 방어와 공격 | 흡수탄 + 소거 에너지, 파동포 | 적탄을 지워 에너지로 바꿔 다음 탄을 강화 |
| 위험 | 원한 저장 + 원한 방출, 빈사 폭주, 위험 수집 | 받은 피해를 저장했다 돌려주고, 체력이 낮을수록 연사가 빨라지고, 위험한 효과를 모을수록 강해짐 |
| 시간과 박자 | 박자 사격 + 완벽한 박자, 연속 처치 콤보 + 콤보 유지, 개전 일제사격 + 개전 재연 | 일정한 박자·콤보·웨이브 시작에 보상 |
| 공간 | 매설탄 + 연쇄 지뢰, 성장탄 + 먼 거리 성장, 닻 내리기 | 박아 두는 탄, 멀리 날수록 커지는 탄, 멈춰 설수록 커지는 탄 |
| 다양성 | 동사 수집가, 반응 공명, 위험 수집 | 서로 다른 탄 동사·이벤트·위험 효과를 많이 가질수록 피해 증가 — 어떤 동사 카드든 파트너가 됨 |

"다양성" 카드는 태그를 `scales` 마스크로 세어서, 필요한 태그가 정해진 다른 증폭과 달리 어떤 동사 카드와도 짝이 된다 (`AugmentSynergy.h`의 `Aug::scales`, `Fx::perTag`).

### 자동 검사 (테스트)

1. 같은 역할·같은 태그·같은 효과 구성의 카드 쌍이 없다 (겹침).
2. 모든 카드에 파트너가 있다 — 동사·트리거·대가·보호는 2장 이상, 증폭·프레임은 1장 이상 (파트너 = 이 카드가 켜주는 카드 + 이 카드를 켜주는 카드).
3. 켜진 카드가 들어간 구성이 평균 구성보다 약하지 않다 (효용 0.97 이상). 쓸모없는 카드를 걸러낸다.
4. 켜졌을 때 위력 배수가 등급 대역 안에 있다 (§8).

## 5. 빌드 예시

시트 `빌드 예시`에 25개가 있다. 사용자가 든 예시는 다음처럼 들어 있다.

| 빌드 | 구성 | 결과 |
|---|---|---|
| 벽에 튕기는 레이저 | 레이저 + 도탄 + 도탄 증폭 + 빔 굵기 | 빔이 벽에서 반사되어 방 안에 격자를 만든다 |
| 미친 저격수 | 저격총 + 유리대포 + 관통탄 + 도탄 + 증폭 | 한 발이 일렬을 뚫고 벽에서 돌아오지만 최대 체력 30 |
| 뽕맛 조합 | 미니건 + 박자 추가탄 + 도탄 + 튕김 반응 | 추가 탄이 도탄 태그를 물려받아 화면이 튕기는 탄으로 가득 참 |

## 6. 카드 드로우

시너지가 있어도 못 만나면 없는 것과 같다. 기존 3장 드로우에 다음을 얹는 것을 제안한다 (아직 구현 안 됨).
1. 첫 증강 선택에서 프레임 3종 중 택1.
2. 보유 태그가 필요 태그인 카드의 등장 확률 ×1.5~2.0 (너무 높으면 선택이 자명해진다).
3. 보유 카드와 연결되는 카드에 작은 연결선 표시 (설명 문구는 건드리지 않음).
4. 코덱스에 발견한 조합 기록.

## 8. 등급 기준

카드가 **켜졌을 때 위력 배수**(그 카드가 켜지는 최소 구성에서 넣기 전후의 위력 비)로 등급을 정한다. 대역은 겹치지 않는다: 일반 1.05~1.20, 희귀 1.20~1.45, 에픽 1.45~1.70, 전설 1.70~2.00, 신화 2.00 이상. 테스트가 모든 카드를 검사한다.

이름은 `Docs/QA/Asteria_증강기획_RnS기반_100.xlsx`의 작명 원칙(R1~R6)을 따른다. 한글만, 2~7음절, 이름 중복 없음, 등급이 높을수록 긴 이름 (테스트가 검사). 효과어(R1)는 눈으로 확인했다.

## 9. 구현 현황

**게임에 연결됨 (2026-11-04)**: 표의 109장 전부. 카드의 이름·태그·수치는 `AugmentSynergy.h`의 표가 기준이고, 게임은 다음 파일로 받는다.

| 파일 | 하는 일 |

| `SynergyRuntime.h/.cpp` | 카드가 게임에서 하는 일 전부. 한 번 쏠 때의 탄 묶음(프레임·쌍발·산개·n번째·개전·메아리), 탄마다 붙는 동사, 맞았을 때·죽였을 때·튕길 때·피격·대시·웨이브 이벤트, 지뢰·잔상 지대·화상·표식 |

| `CollisionSystem.h`, `ProjectileSystem.cpp` | 포탄은 길 위의 적을 맞히지 않음, 표적 반사, 벽에서 튕겼을 때 알림 |

카탈로그에는 기존 카드 뒤, 레벨업 카드(S_*) 다음에 붙였다 (저장된 도감 번호가 밀리지 않도록). 한 런에 프레임은 하나만 나온다.

**기존 카드는 빌드에서 제외 (2026-11-04)**: 첫 릴리스의 패시브(P_*)·액티브(A_*) 카드는 더 이상 나오지 않고 도감에도 보이지 않는다. 한 런에 나오는 카드는 시너지 카드와 레벨업 능력치 카드(S_*)뿐이다. 코드와 카탈로그 행은 남겨 저장된 번호가 밀리지 않고, `Augment.h`의 `kLegacyAugments`를 `true`로 바꾸면 되살아난다.

**규칙 글을 구현에 맞게 바꾼 카드**: 저격총(충전 대신 느리지만 묵직한 관통탄), 박자 사격(4번째 사격마다 강화탄), 레이저(빔 대신 빠른 광선 탄 — 조작 입력은 자동 연사라서), 차지 증폭(장전 30% 빠름). 수치가 표의 균형 모델과 다른 곳은 규칙 글의 숫자를 따랐다.

**아직 없는 것**: 카드 아이콘, 카드 드로우 가중(§6), 코덱스 조합 기록, 프레임 외형(레이저는 점선처럼 보이는 빠른 탄).

**확인 방법**: `test_augment_catalog.ps1`(표와 등록이 어긋나지 않는지), `test_augment_synergy.ps1`(균형·겹침·파트너·효용), 게임 스모크(`ASTERIA_SMOKE`의 `GIVE=SYN_<코드>`로 카드를 주고 처치 수 비교).
