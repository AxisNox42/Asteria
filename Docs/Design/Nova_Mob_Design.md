# NOVA 일반 몹 설계 (v1, 초안)

작성일: 2026-11-06 · 설계만 있고 코드·도안은 아직 없다. 수치는 모두 플레이 검증 전 초안이다.

## 왜 필요한가

현재 잡몹은 근접 돌진(SWARM, ROTOR, GIMBAL), 원거리(SCOPE, LYNX), 방해·장악(GRAVIS, MAGNETAR, MIRA)뿐이다. 순간적으로 터지는 광역 위협이 없다. 플레이어가 위치와 타이밍을 골라 피해야 하는 몹을 하나 둔다. 소환·지원 역할은 엘리트에게만 있어서 이 몹과 겹치지 않는다.

## 모델

NOVA (신성). 평소에는 어두운 별이다가 한순간 폭발해 밝아진다. 가까이 오면 터지는 것이 이 몹의 전부다.

## 외형

선만 쓴다. 면 채움, 점선, 가시는 쓰지 않는다.

- 코어: 작은 다이아몬드를 겹쳐 둔 모양 두 겹. 두 겹 사이를 이어 주는 선으로 밀도를 낸다.
- 폭발 범위: 코어 둘레의 얇고 어두운 실선 고리. 평소에는 희미하게 항상 보인다.
- 점화 중: 범위 고리가 밝아지고, 코어에서 안쪽 고리가 커져서 범위 고리에 닿는 순간 터진다. 진행은 실선 고리의 크기로만 보인다.

## 행동

1. **접근**: 플레이어 쪽으로 걸어온다. 속도는 로터보다 약간 느리다.
2. **점화**: 플레이어가 점화 거리 안에 들어오면 그 자리에 멈추고 퓨즈를 켠다. 점화 거리는 폭발 반지름보다 약간 크다. 점화 중에는 움직이지 않는다.
3. **폭발**: 퓨즈가 끝나면 폭발 반지름 안의 플레이어에게 한 번 피해를 준다. 점화가 시작된 뒤에 범위를 벗어나면 맞지 않는다.

점화 중에는 제자리에 있으므로 달려서 벗어나거나 그 전에 죽이는 선택지가 생긴다. 다른 몹과 함께 오면 피할 곳이 줄어든다는 것이 위협의 핵심이다.

## 죽을 때

- 점화 전에 잡으면 아무 일도 없다 (작은 흩어짐 연출만).
- 점화 중에 잡으면 퓨즈가 중단되고 폭발하지 않는다.
- 폭발 피해는 플레이어에게만 준다. 몹끼리 피해를 주는 것은 열린 질문이다.

## 스탯 (초안)

| 항목 | 값 |
|---|---|
| 체력 | 로터의 1.2배 |
| 이동 | 로터의 0.8배 |
| 점화 거리 | 약 170px |
| 퓨즈 시간 | 약 1.0초 |
| 폭발 반지름 | 약 140px |
| 폭발 피해 | 초안 30 (플레이어 체력 기준으로 조정 필요) |

| 동시 최대 | 5마리 (넘으면 일반 스폰이 로터로 바뀐다) |
| 보상 | 경험치 3, 점수 180 (임시) |

## 등장 설정 (임시값)

- 엘리트·보스 웨이브에는 첫 등장을 두지 않는다 (`WaveSystem.h`의 `kWaveSchedules` 확인 필요).

## 열린 질문

- 폭발이 다른 몹에게 피해를 줄지 (주면 유도해서 쓰는 재미가 생기지만 밸런스가 어려워진다).
- 퓨즈를 잡는 동안 멈추는 것으로 충분한지, 아니면 플레이어를 향해 짧게 돌진할지.
- 폭발 피해 30이 현재 체력 규모에서 적절한지.
