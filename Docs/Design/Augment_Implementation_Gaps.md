# 증강 구현 점검 — 근사로 만든 것, 아직 없는 것, 앞으로의 구상 (2026-11-04)

시너지 카드 109장은 모두 게임에 들어가 있다 (`SynergyRuntime.cpp`). 다만 일부는 **규칙 글을 구현 가능한 모양으로 바꾼 근사**이고, 일부는 **동작은 하지만 화면에 보이지 않았다**. 이 문서는 그 목록과 완성 방법이다. 점검은 (1) 카드 효과를 읽는 코드가 있는지 자동으로 훑고, (2) 코드와 규칙 글을 카드마다 대조하고, (3) 스모크 화면을 직접 본 결과다.

## 1. 규칙 글과 다르게 근사한 카드

| 카드 | 지금 하는 일 | 부족한 점 | 완성 구상 |
|---|---|---|---|
| 저격총 `F_SNIPER` | 느리고 묵직한 관통탄 | 충전이 없다 (원래 글은 "누르면 충전, 떼면 발사") | 사격 키를 누르고 있는 동안 게이지가 차고 놓으면 발사. 충전 0~100%에 비례해 피해 ×1~×3. 자동 사격 경로(`fireHeld`)와 분리해 `ChargeState`를 두고, 플레이어 호 옆에 가는 충전 호를 그린다. 차지 증폭은 충전 속도 +30% |
| 레이저 `F_LASER` | 아주 빠른 탄을 연달아 쏨 | 점선처럼 보이고, 빔이 아니다 | 선분 빔: 플레이어에서 조준 방향으로 선분을 그리고(굵기 `A_BEAM`), 10Hz로 선분과 겹친 모든 적에게 틱 피해. 벽에 닿으면 선분 반사(`V_BOUNCE`)로 꺾인 선분을 이어 그린다. 필요한 것: 선분–원 교차, `DrawLine` 한 번, 반사 횟수 제한 |
| 점사총 `F_BURST` | 3발을 동시에 부채꼴로 | 점사의 "끊어 쏘는" 리듬이 없다 | 0.06초 간격 3발. `Echo`와 같은 지연 큐를 재사용해 볼리 안에서 시간차로 내보낸다 |
| 박자 사격 `T_RHYTHM`, 완벽한 박자 `A_RHYTHM` | 4번째 사격마다 ×3(×6) | 박자를 맞추는 조작이 없다 (사격이 자동이라서) | 수동 사격(마우스 누름)에서만 "직전 사격과 0.4초 ±0.07초면 박자 성공" 판정, 성공 4연속이면 강화탄. 자동 사격 중에는 지금처럼 4번째마다. 박자를 맞추는 순간 짧은 틱 소리와 링으로 알려 준다 |
| 연사 증폭 `A_RAPID` | 미니건 탄 피해 +35% | 원래 글("연사가 빠를수록 탄당 피해 감소가 줄어듦")과 다르다 | 글을 지금 동작에 맞췄다. 원래 의도로 가려면 연사 배율에 비례해 미니건의 탄 피해 감소(-60%)를 줄이는 식으로 `dmg`를 동적으로 계산 |
| 집요한 사냥탄 `V_HUNTER` | 모든 탄이 520px 가서 돌아옴 | "표적을 놓쳤을 때만" 돌아오지 않는다 | 유도 중 적에게 맞히면 소멸, 사거리 끝까지 못 맞혔을 때만 `Returning`으로 전환. 되돌아올 때 가장 가까운 적을 다시 노림 |
| 회피 반격 `G_PARRY` | 대시 무적 0.45초 + 끝날 때 탄 소거 | "대시 중 전체"가 아니다 | 대시 지속 시간(`dashProgress`)과 같은 길이로 무적을 유지 |
| 차지 증폭 `A_CHARGE` | 연사 +30% (장전이 빨라짐) | 충전이 없어서 글만 바꿈 | 저격총 충전 도입 후 충전 속도 +30%로 되돌린다 |
| 레이저 굵기 `A_BEAM` | 탄 크기 +, 피해 +25% | 빔이 없어서 굵기가 약하게 보임 | 빔 도입 후 선분 굵기 +40% |

## 2. 동작은 하지만 보이지 않던 것 (이번에 일부 해결)

| 효과 | 이전 | 지금 | 남은 일 |
|---|---|---|---|
| 카드를 얻었을 때 | 아무 표시 없음 | 등급 색의 링(등급이 높을수록 겹겹), 파편, 카드 이름이 떠오름, 에픽 이상은 화면 번쩍임 | 얻는 효과음을 등급별로 |
| 잔상·벽 균열·잔영 지대 | 보이지 않고 피해만 줌 | 지대 가장자리에 점 링이 0.3초마다 맥동 (잔상 주황, 벽 균열 하늘색, 잔영 보라) | 지대가 많을 때를 위한 합치기 |
| 지뢰 | 보이지 않음 | 빨강 점 링 두 겹이 0.6초마다 맥동 | 폭발 직전 깜빡임 |
| 표식 | 보이지 않음 | 표식 붙은 적 위에 노랑 링이 0.7초마다 | 표식 개수 상한 표시 |
| 화상 | 보이지 않음 | 불탈 때마다 주황 점이 튐 | 불타는 적의 윤곽 색 |
| 보호막 | HUD 숫자만 | 보호막이 있는 동안 플레이어 둘레에 하늘색 링이 맥동 | 보호막이 깨질 때 파편 |
| 자리바꿈 | 보이지 않음 | 떠난 자리와 도착 자리에 링 | 이동 궤적 |

여기서 하나 발견한 것: **`g_Sparks`(맞았을 때 튀는 불꽃)는 어디에서도 그려지지 않는다.** 갱신만 되고 그리는 코드가 없다. 그래서 링은 실제로 그려지는 적 파티클 풀(`g_EnemyParts`)로 만들었다. 불꽃을 되살릴지는 따로 정해야 한다 (피격 불꽃이 갑자기 많이 보이게 된다).

아직 눈에 보이지 않는 카드와 구상:

| 카드 | 구상 |
|---|---|
| 에코 `Y_ECHO` | 메아리 볼리는 반투명(알파 0.5) 탄으로 그린다 (`Bullet`에 `ghost` 플래그) |
| 주사위탄 `V_DICE` | 발사 때 탄 색이 결과(관통·분열·튕김·폭발)별로 다르게 |
| 흡수탄·파동포 `V_ABSORB`, `F_WAVE` | 적탄이 지워질 때 작은 링과 흡수한 에너지 게이지(플레이어 호 옆) |
| 원한 저장 `T_GRUDGE` | 저장된 피해량을 플레이어 둘레의 붉은 호로 |
| 콤보·정지 반응·닻 `T_COMBO`, `T_STILL`, `T_ANCHOR` | 충전 상태를 플레이어 호 옆 작은 눈금으로 |
| 유리대포 `C_GLASS` | 플레이어 윤곽을 유리빛으로, 체력 30 표시 |
| 중력탄 `V_GRAVITY`, `Y_SINGULAR` | 끌어당기기 전에 안쪽으로 모이는 링 |
| 성장탄 `V_GROW` | 이미 커지지만 색이 점점 밝아지게 |
| 매설탄 폭발 | 터지는 반경에 링 (지금은 `Burst`의 주황 링) |

## 3. 카드 선택·도감 쪽 빈 곳

| 항목 | 구상 |
|---|---|
| 카드 아이콘 109개 | 카드 화면에서 비어 있다. 역할별 기본 글리프(프레임·동사·트리거·증폭·대가·보호·신화)를 선 그림으로 그려 우선 채우고, 이후 카드별로 교체. `AugIconTex`가 없는 파일에 0을 돌려주므로 기본 글리프로 폴백하는 한 줄을 추가 |
| 카드 드로우 가중 | 보유 태그가 필요한 카드의 등장 확률 ×1.5~2.0 (`PickRewardChoices`에서 `CanOffer`를 통과한 카드에 가중). 가중이 너무 크면 선택이 자명해진다 |
| 코덱스 조합 기록 | 한 런에서 "필요 태그가 켜진" 카드 쌍을 `Codex.h`에 기록, 도감에 "발견한 조합" |
| 활성 시너지 표시 | 일시정지 화면에 보유 태그와 켜진 카드/꺼진 카드를 보여 주기 (꺼진 카드는 필요한 태그를 알려 줌) |
| 수치 보정 | 게임의 수치는 카드 글을 따랐고 균형 모델과 다르다. 텔레메트리로 웨이브별 처치 시간·피해를 모아 표의 `Fx`를 실제에 맞춰 다시 조정 |

## 4. 이번에 바꾼 것

- 처치를 세는 방식: 탄이 죽인 것만이 아니라 화상·지대·폭발·스킬이 죽인 것도 콤보·처치 반응·연쇄·순환 방벽·화상 번짐에 센다 (적이 이번 스텝에 사라졌는지 비교).
- 자리바꿈탄이 "대시처럼 취급"되도록: 자리를 바꾸면 대시 끝 효과(대시 폭죽, 회피 반격)도 바로 나간다.
- 상위 등급 확률: 일반 50→44, 희귀 25, 에픽 12→15, 전설 5→8, 신화 3→4 (가중치 합 95→96). 한 번 뽑을 때 에픽 이상이 나올 확률은 21.1%에서 28.1%로 올랐다 (웨이브가 올린 등급 상한을 넘는 등급은 여전히 나오지 않고, 행운은 일반이 아닌 가중치에 그대로 곱해진다).
